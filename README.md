# usage-meter

A Claude Code pane that shows your current 5-hour session limit and your weekly (7-day) limit, with reset times. Reopen it with `/usage-meter`.

## Install

At the prompt of a Claude Code session:

```
/plugin install usage-meter --marketplace chrisamonson-ui/usage-meter
```

Answer `y` to add the marketplace, then pick a scope (user scope makes it load in every session).

This repository is private, so the computer needs git access to GitHub (signed in) to install it.
